# Mode d'emploi MBoté

## Objectif

Ce document explique l'utilisation des fonctionnalités principales de MBoté : compte, discussions, appels, réunions, Actus, statuts, vidéos courtes, contacts, emplois, outils IA, rappels, notifications, paramètres et portails d'administration.

Les fonctions visibles peuvent varier selon le rôle du compte, l'appareil, les permissions accordées et la connexion réseau. Les fonctions Premium ou entreprise affichent une demande d'accès lorsqu'elles ne sont pas disponibles.

## 1. Première utilisation

### Ouvrir MBoté

Ouvrez MBoté dans le navigateur ou depuis l'application installée. La page de connexion propose :

- Connexion ;
- Création de compte ;
- Mot de passe oublié ;
- Connexion sociale Google ou GitHub lorsque cette option est activée.

### Créer un compte

1. Sélectionnez **Créer un compte**.
2. Choisissez un compte personnel ou professionnel si l'option est proposée.
3. Renseignez votre nom, identifiant, date de naissance et coordonnées.
4. Choisissez le pays et la ville.
5. Créez un mot de passe sécurisé.
6. Lisez et acceptez les conditions d'utilisation.
7. Validez le code OTP reçu par e-mail ou WhatsApp.
8. Connectez-vous.

Utilisez une adresse e-mail et un numéro auxquels vous avez accès. Ne partagez jamais votre mot de passe ou votre code OTP.

### Se connecter

1. Saisissez l'e-mail ou le numéro de téléphone.
2. Saisissez le mot de passe.
3. Activez **Se souvenir de moi** uniquement sur un appareil personnel.
4. Sélectionnez **Se connecter**.

### Mot de passe oublié

1. Sélectionnez **Mot de passe oublié ?**
2. Saisissez votre adresse e-mail.
3. Sélectionnez **Envoyer le lien**.
4. Ouvrez le message reçu.
5. Choisissez un nouveau mot de passe.

Vérifiez les courriers indésirables si le message n'arrive pas. Ne transférez jamais un lien de réinitialisation.

### Session expirée

Si MBoté affiche une session expirée, reconnectez-vous. Les pages protégées redirigent automatiquement vers la connexion lorsque la session n'est plus valide.

## 2. Navigation

La barre mobile propose généralement :

- **Actus** : publications et actualités ;
- **Appel** : appels et historique ;
- **Message** : discussions ;
- **Réunions** : réunions planifiées ;
- **Paramètres** : compte, apparence, notifications et sécurité.

Selon l'écran, **Outils**, **Emplois**, **Contacts**, le profil et les fonctions supplémentaires se trouvent dans le menu ou le tableau de bord. Les badges indiquent les messages ou activités non lus.

## 3. Tableau de bord et profil

### Tableau de bord

Le tableau de bord regroupe les raccourcis vers les conversations, appels, contacts, contenus, réunions, emplois et services MBoté. Sélectionnez **Message** dans la barre mobile pour y revenir.

### Consulter un profil

Sélectionnez le nom ou l'avatar d'un utilisateur depuis une discussion, un commentaire, une notification ou une liste de contacts. Les informations visibles dépendent de la confidentialité du profil.

### Modifier son profil

Dans **Paramètres**, ouvrez la section du profil pour modifier le nom, l'e-mail, le numéro, l'avatar et les informations personnelles ou professionnelles. Enregistrez puis contrôlez la visibilité du résultat.

## 4. Discussions et messages

### Nouvelle discussion

1. Ouvrez **Message**.
2. Sélectionnez une discussion ou **Nouvelle discussion**.
3. Recherchez un contact par nom, identifiant, e-mail ou numéro.
4. Sélectionnez la personne.
5. Écrivez le message et sélectionnez **Envoyer**.

### Contenus envoyés

Selon l'appareil et les permissions, une discussion permet d'envoyer :

- texte ;
- emojis ;
- images et médias ;
- messages vocaux ;
- liens ;
- réponses à un message.

Autorisez le microphone ou la caméra si l'application le demande.

### Message vocal

Sélectionnez le bouton d'enregistrement, parlez, écoutez l'aperçu si disponible, puis envoyez ou annulez. Vérifiez le destinataire avant d'envoyer un contenu confidentiel.

### Rechercher dans une discussion

Utilisez la recherche de la conversation pour retrouver un message ou un contenu. Les résultats peuvent dépendre des données déjà synchronisées.

### Créer un groupe

1. Ouvrez **Nouvelle discussion**, puis **Nouveau groupe**.
2. Recherchez et sélectionnez les participants.
3. Donnez un nom au groupe.
4. Validez.
5. Envoyez le premier message.

Les administrateurs du groupe peuvent disposer d'actions supplémentaires : gestion des membres, informations du groupe et modération des messages.

### Chaînes

Les chaînes servent à diffuser des publications à une audience. Créez la chaîne, renseignez son nom et ses informations, puis publiez depuis l'espace Actus ou le menu de création. Contrôlez la visibilité avant chaque publication.

## 5. Contacts

### Rechercher et ajouter

1. Ouvrez **Contacts**.
2. Recherchez par nom ou identifiant.
3. Ouvrez le profil.
4. Ajoutez le contact ou démarrez une discussion.

### Compte privé

Pour ajouter un compte MBoté privé, utilisez son identifiant, son e-mail ou son numéro lorsqu'une option dédiée est proposée. N'ajoutez que des personnes connues ou autorisées.

### Bloquer

Depuis le profil ou les paramètres de confidentialité, utilisez le blocage. Consultez la liste des comptes bloqués pour rechercher ou rétablir un contact si l'option est disponible.

## 6. Appels

### Appel audio ou vidéo

1. Ouvrez **Appel**.
2. Recherchez un contact ou un groupe.
3. Choisissez audio ou vidéo.
4. Autorisez le microphone et la caméra.
5. Utilisez les commandes pour couper le micro, désactiver la caméra ou terminer.

Une connexion stable et un casque améliorent la qualité.

### Appel de groupe

Recherchez un groupe ou ajoutez plusieurs participants dans l'espace Appel. Prévenez les participants avant d'activer la caméra.

### Planifier

La fonction **Planifier** accepte notamment :

- appel vidéo ;
- appel audio ;
- message vocal.

Saisissez le destinataire, la date, l'heure et le sujet, puis sélectionnez **Planifier maintenant**. Les notifications doivent être autorisées.

### Localisation

Si une localisation d'ami est disponible, utilisez-la uniquement avec le consentement de la personne. Ne partagez pas une localisation sans autorisation.

## 7. Réunions

### Créer

1. Ouvrez **Réunions**.
2. Sélectionnez **Créer**.
3. Saisissez le titre.
4. Ajoutez une description si nécessaire.
5. Choisissez les participants ou le mode de partage.
6. Validez.

### Rejoindre

Ouvrez la réunion depuis la liste ou le lien reçu. Une réunion peut aussi être rejointe depuis une URL de type /join. Vérifiez le nom de la réunion et les participants avant d'activer le micro ou la caméra.

### Pendant la réunion

Vous pouvez, selon les droits :

- couper ou activer le microphone ;
- couper ou activer la caméra ;
- consulter les participants ;
- quitter ;
- envoyer un retour après l'appel.

## 8. Actus et publications

### Consulter

Ouvrez **Actus**, faites défiler les publications, recherchez un sujet et ouvrez une publication pour son contenu complet. Les réactions, commentaires et partages sont proposés selon le contenu.

### Publier

1. Sélectionnez l'action de création dans **Actus**.
2. Ajoutez un titre.
3. Écrivez le contenu.
4. Ajoutez une image, vidéo ou des hashtags si nécessaire.
5. Choisissez la visibilité.
6. Publiez.

Relisez avant l'envoi. Une publication publique peut être vue par des personnes inconnues.

### Commenter

Sélectionnez **Exprimez-vous...**, écrivez le commentaire et publiez. Utilisez les réponses pour suivre un fil. Ne publiez pas de données personnelles.

### Créer un statut

1. Ouvrez la création de statut.
2. Choisissez texte, image, audio ou caméra.
3. Ajoutez le texte, la légende et les emojis.
4. Contrôlez l'audience.
5. Publiez.

Les statuts peuvent être temporaires. Vérifiez leur durée et leur visibilité.

### Signaler ou ignorer

Utilisez le menu d'une publication, d'un commentaire ou d'une notification pour ignorer, masquer ou signaler. Décrivez précisément le motif : spam, fraude, harcèlement, usurpation ou contenu interdit.

## 9. Vidéos courtes

1. Ouvrez **Short vidéos**.
2. Faites défiler les vidéos.
3. Utilisez les réactions et commentaires disponibles.
4. Ouvrez le profil de l'auteur si nécessaire.
5. Signalez un contenu problématique depuis son menu.

La vidéo consomme des données mobiles ; le Wi-Fi est recommandé.

## 10. Emplois

### Rechercher

1. Ouvrez **Emplois**.
2. Recherchez un métier, une entreprise ou une ville.
3. Ouvrez une offre.
4. Vérifiez la source, l'entreprise, les dates et l'expiration.
5. Sélectionnez **Voir** ou **Postuler**.

Les offres peuvent être agrégées depuis MBoté et des sources publiques. Vérifiez toujours l'identité du recruteur et l'URL avant d'envoyer des documents.

### Aimer, partager et masquer

Utilisez le cœur pour aimer, le partage pour copier ou envoyer le lien et l'action de masquage pour retirer une offre de votre liste.

### Publier une offre

1. Sélectionnez **Publier un emploi**.
2. Renseignez le poste et l'entreprise.
3. Ajoutez lieu, type de contrat, domaine et pays.
4. Ajoutez l'e-mail ou l'URL de candidature.
5. Indiquez durée, salaire, expiration et description.
6. Publiez.

Ne demandez jamais d'argent à un candidat pour accéder à une offre.

## 11. Outils

Ouvrez **Outils** depuis le menu principal.

### Rappels et tâches

1. Ouvrez **Rappels & Tâches**.
2. Sélectionnez **Créer**.
3. Saisissez le titre, la date et l'heure.
4. Sélectionnez **Programmer le rappel**.
5. Consultez les éléments dans **Mes rappels**.

Les notifications doivent être autorisées. Une date passée est refusée.

### Outils IA

Les outils IA comprennent notamment :

- **Générateur d'images IA** : décrivez l'image, générez-la et vérifiez le résultat ;
- **Amélioration de texte** : saisissez un texte, choisissez professionnel, amical ou enthousiaste, puis relisez la proposition ;
- **Groupes d'actions IA** : enchaînez des actions comme traduire, améliorer et préparer une réponse ;
- **Fil d'actualités IA** : consultez des actualités personnalisées ;
- **Statistiques IA** : suivez les requêtes et types de tâches ;
- **Historique IA** : retrouvez les échanges précédents.

L'IA peut se tromper. Vérifiez toujours les noms, dates, montants, sources et engagements. Ne saisissez pas de mot de passe, clé API ou donnée bancaire.

Les outils IA peuvent demander un compte Premium.

### Outils business

Selon le compte, les outils business peuvent comprendre :

- message d'accueil ;
- message d'absence ;
- réponses rapides ;
- profil Business ;
- Facebook et Instagram ;
- analytiques.

Ces fonctions peuvent être réservées aux comptes entreprise.

## 12. Notifications

### Lire

Ouvrez le panneau Notifications depuis la cloche ou le menu. Les notifications peuvent concerner messages, réactions, commentaires, contacts, statuts, vidéos, réunions, appels ou emplois.

### Actions

Depuis une notification, utilisez selon le type :

- ouvrir le contenu ;
- ouvrir le profil ;
- marquer lu ou non lu ;
- ignorer ;
- supprimer ;
- marquer tout comme lu.

Sur mobile, un balayage latéral peut permettre d'ignorer une notification.

### Écran verrouillé

Pour afficher les notifications téléphone verrouillé :

1. autorisez les notifications dans MBoté ;
2. autorisez-les dans Android ou iOS ;
3. activez l'affichage sur écran verrouillé ;
4. contrôlez la confidentialité du contenu.

Désactivez l'aperçu si le téléphone est partagé.

## 13. Paramètres

### Apparence

Gérez le thème clair ou sombre, la couleur et certains éléments d'affichage. Revenez à l'écran principal pour contrôler le résultat.

### Notifications

Gérez les alertes, sons, notifications de messages, rappels et permissions du navigateur ou du téléphone.

### Confidentialité et sécurité

Vérifiez :

- visibilité du profil ;
- comptes bloqués ;
- sessions actives ;
- permissions caméra et microphone ;
- permissions de notifications ;
- informations partagées.

Déconnectez-vous sur un appareil partagé.

### Compte et assistance

Modifiez les informations du compte, déconnectez-vous et utilisez le formulaire de retour pour signaler un problème. Décrivez l'écran, l'action, le résultat obtenu, le résultat attendu, l'appareil et le navigateur.

## 14. Installation et QR

### Installer

Lorsque le navigateur propose **Installer MBoté** ou **Ajouter à l'écran d'accueil**, acceptez puis ouvrez l'application depuis l'icône. L'installation PWA ne rend pas les fonctions serveur disponibles hors ligne.

### Associer par QR

1. Ouvrez l'option QR.
2. Affichez le code sur l'appareil à associer.
3. Scannez-le depuis l'appareil déjà connecté.
4. Confirmez.
5. Vérifiez les sessions actives.

Ne partagez jamais une capture de QR de connexion. Révoquez une session si un appareil est perdu.

## 15. Mode hors connexion

Le mode hors connexion utilise uniquement les données déjà enregistrées localement.

- Les nouvelles données serveur ne sont pas garanties hors ligne.
- Les actions en attente se synchronisent au retour du réseau.
- Laissez l'application ouverte après le retour de la connexion.
- Utilisez la synchronisation si une action reste en attente.
- Évitez d'effacer les données du navigateur si vous voulez conserver le cache.

## 16. Portails d'administration

Ces espaces sont réservés aux rôles autorisés.

### Connexion

- Administrateur : /admin/login
- Modérateur : /moderateur/login

Un compte sans rôle autorisé est redirigé vers l'application principale.

### Administration

Selon le rôle, les écrans peuvent inclure :

- tableau de bord de sécurité ;
- utilisateurs ;
- rapports et détail d'un rapport ;
- modération ;
- journaux d'audit ;
- rôles ;
- paramètres ;
- modération assistée par IA.

### Modération

Le portail modérateur peut inclure les signalements, détails, recours et actions autorisées. Documentez chaque action et consultez uniquement les données nécessaires.

## 17. Dépannage

### Je ne reçois pas l'OTP

Vérifiez l'adresse ou le numéro, les courriers indésirables, le réseau et attendez avant de redemander un code.

### Les messages ne partent pas

Vérifiez le réseau, la bannière de synchronisation, la discussion et l'état de la session. Reconnectez-vous si nécessaire.

### Microphone ou caméra indisponible

Autorisez la permission dans le navigateur et le système, fermez les autres applications utilisant la caméra, puis rechargez MBoté.

### Notifications absentes

Vérifiez les réglages MBoté, du navigateur ou du téléphone. Désactivez temporairement l'économie d'énergie et testez avec l'application ouverte.

### Écran vide

Rechargez MBoté, vérifiez le réseau et reconnectez-vous. Pour un signalement, indiquez l'URL, l'écran, l'heure et le navigateur.

### Fonction verrouillée

Un message Premium ou entreprise signifie que la fonction nécessite le niveau d'accès correspondant. Contactez le responsable du compte ou MBoté.

## 18. Sécurité

- Utilisez un mot de passe unique.
- Verrouillez le téléphone.
- Ne partagez jamais OTP, QR ou mot de passe.
- Vérifiez les liens et les recruteurs.
- Contrôlez la visibilité avant de publier.
- Signalez les abus et fraudes.
- Déconnectez les appareils partagés.
- Maintenez système et navigateur à jour.
